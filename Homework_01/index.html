Основи вебтехнологій

Технології для створення вебсторінок

HTML визначає структуру сторінки: заголовки, абзаци, посилання, зображення та інші елементи.

CSS відповідає за вигляд сторінки — кольори, шрифти, відступи та розташування елементів.

JavaScript додає інтерактивність: допомагає реагувати на дії користувача та оновлювати вміст сторінки.
